---

## 🌟 About the Project
- 📍 Displays **synthetic incidents** on an interactive map
- 🧪 Designed for **learning, testing, and visualization** of geo-spatial data
- 🗺️ Focuses on **frontend map integration and marker plotting**
- ⚡ Lightweight project with **no backend dependency**

---

## 🎯 Project Objective
- To understand **map APIs and marker rendering**
- To simulate **real-world incident locations using synthetic data**
- To visualize how **location-based data** can be displayed effectively on maps
